# SherpaPay Web

Next.js 15 web application for SherpaPay — plain-English payments on Celo.

## Features

- Mobile-first responsive design
- RainbowKit wallet connection (Celo + Alfajores)
- Natural language input for payments
- Schedule management
- Savings goals
- Transaction history

## Development

```bash
pnpm dev:web
```

Open http://localhost:3000
